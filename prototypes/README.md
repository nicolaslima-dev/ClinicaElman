# Clínica Elman - Protótipos

Esta pasta reúne as páginas originais de referência da Clínica Elman. Elas servem de guia visual (gabarito estético e funcional) para a recriação em componentes JSX/TSX na pasta `frontend/`.

## Arquivos Disponíveis

* `index.html`: Dashboard Executivo
* `login.html`, `login_v2.html`: Tela de Login corporativa
* `esqueceu-senha.html`: Fluxo de Recuperação de Senha
* `novo_atendimento.html`, etc.
* `app.js` e assets relacionados.

> **Importante:** Estes arquivos não devem ser apagados nem alterados neste momento, pois são o nosso material de consulta primário para o layout e funcionalidades legadas.
